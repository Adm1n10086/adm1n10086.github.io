# 前提：

0day防护，有一个非常重要的动作：加强主机安全防护 ——增加安全设备的部署（主流是EDR和HIDS<主机入侵检测系统>）

# 什么是EDR？

EDR，全称Endpoint Detection and Response，是一种用于检测、预防、响应和预测计算机或网络中发生的安全威胁的技术和方法。它通过在端点上收集各种日志和事件数据，实时监控和分析这些数据，以发现异常行为或潜在的安全威胁，并采取相应的措施进行响应。与SIEM相比，EDR更注重端点安全，强调端点检测与响应

# 四大功能

实时监控：EDR系统实时监控端点设备的活动，包括文件访问、进程执行、网络连接等，以便识别异常行为。
威胁检测：它使用行为分析、签名匹配、机器学习等技术来检测潜在的威胁和攻击模式。
威胁响应：EDR能够快速响应检测到的威胁，采取措施如隔离感染设备、阻止攻击传播、修复漏洞等。
调查和分析：它提供详细的事件日志和威胁情报，有助于安全团队进行调查和分析，了解攻击的来源和影响。

# 工作原理

1、各个服务器终端安装Agent;
2、通过Agent将“行为数据：进程、网络访问、文件特征..、静态样本、系统，软件特征、硬件特征等信息上传分析平台（服务端）
3、服务端通过1）威胁情报2）沙箱3）AI模型等进行分析
4）通过服务端的分析后对那些危险的样本进行隔离、危险进程进行阻断等。

# EDR与传统杀毒软件的区别


对于端点安全，传统杀毒软件
是怎么做的？
传统杀毒软件是基于签名的，所以它只识别已知的威胁。
传统杀毒软件可以包括定期或定期扫描受保护设备，以检测已知的威胁协助清除更基本的病毒（蠕虫，木马，恶意软件，广告软件，间谍软件等）
基于数据库来提供关于可能恶意网站的警告

对于端点安全，EDR（终端检测与响应）是怎么做的？
EDR 包括对威胁的实时监控和检测，包括那些可能不容易被标准反病毒识别或定义的威胁。此外，EDR是基于行为的，因此它可以基于不正常的行为检测未知的威胁。
基于大数据和人工智能的数据收集和分析系统，以此确定威胁模式，并向用户发出威胁警报附带取证功能可以帮助确定在安全事件中发生了什么攻击行为
EDR 可以包括对某些威胁的自动修复或移除，例如主机的微隔离，通过控制主机的进出站流量，实现对异常主机的隔离。
总的来说杀毒只能对已知的病毒进行查杀，且不能知晓攻击路径或漏洞点；EDR 根据行为则可以应对 Oday 攻击，
且能分析出攻击路径。

# EDR选型需要注意的陷阱和误区

IDC安全与信任研究副总裁MichaelSuby表示，EDR最大的陷阱（误区）是很多企业认为EDR是“一劳永逸”的解决方案：“你不能想当然地认为只需要购买并运行EDR工具就可以解决一切问题。事实并非如此，你还必须拥有足够的内部人才，能够有效地学习和操作EDR软件。“就初始投资和持续维护成本而言，EDR产品比传统防病毒软件更昂贵，这使得购买、实施和维护EDR工具对于中小型企业来说成本过高。除了投资和运维成本高以外，EDR常见的“坑”是企业没有足够经验丰富的操作人员来使用该软件。EDR软件对操作人员的技能要求通常较高，因为操作人员需要追踪事件的路径，并根据行为确定其是否恶意。这意味着无论是招聘还是外包，EDR都会带来人力相关成本的增加。

最后，一些EDR工具的可扩展性有限，不能伴随公司发展过程持续改善其安全状况。在高峰使用期间，有限的可扩展性可能会导致延迟或停机，从而影响企业快速检测和响应安全事件的能力。

EDR要注意带宽的使用，因为他使用的不是本地的计算机资源，更多的是把信息传递到服务端，，所以要特别注意带宽的使用，特别是专网上，大量的agent采集的数据，通过专网汪服务器传递，就会导致网络堵塞。
